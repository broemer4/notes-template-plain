# LaTeX Template

This template is a simple LaTeX template that can be used as a starting point for writing documents.

## Usage

1. Clone or fork the repository to your local computer.
2. Edit the file `main.tex` with your preferred text editor to add the content of your document.
3. Compile the LaTeX system to compile the document. Depending on which LaTeX system you use, you may need to execute different commands to compile the document correctly.
4. The resulting document will be saved in the file `main.pdf`.

## Editing `main.tex`

- The document type is set as `article`, but you can change it to `report`, `book`, or other similar document types by modifying the first line.
- The packages and settings in the file `preamble.tex` can be modified to adjust the formatting of the document.
- The content of the document can be added directly to the file `main.tex` or split into separate files, which can then be included in the file `main.tex` using the command `\input{filename.tex}`.
